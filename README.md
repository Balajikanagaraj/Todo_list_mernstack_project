# Todo List Application

## Overview:
This Todo List web application allows users to add, mark as completed, and delete tasks. It is built using **Node.js**, **Express.js**, **MongoDB**, and **EJS** for the frontend. The app is designed to be simple, effective, and easy to use, with the core feature being task management.

## Features:
- **Add Tasks**: Users can enter a new task into the system through an input field.
- **Complete Tasks**: Users can mark tasks as completed by checking a checkbox, which strikes through the task text.
- **Delete Tasks**: Users can delete tasks from both the UI and the database.
- **Persistence**: All tasks are saved in MongoDB, so they persist even after refreshing the page.

## Technologies Used:
- **Frontend**:
  - **EJS**: Templating engine used to dynamically render the task list.
  - **HTML/CSS**: Used to structure and style the user interface.
  - **JavaScript**: Handles task completion and deletion interactions.
- **Backend**:
  - **Node.js**: JavaScript runtime used to build the backend.
  - **Express.js**: Web framework for routing HTTP requests.
  - **MongoDB**: Database used to store tasks.
